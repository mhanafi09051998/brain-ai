# CLAUDIA.md — Project Instructions & Architecture Rules

## The Minimality Ladder Directives:
1. YAGNI: Do not add speculative abstractions or unnecessary helpers.
2. Standard Library First: Use native platform features before pulling new packages.
3. Root Cause Fixing: Patch the shared root function once.
4. Minimal Working Diffs: Always write the shortest verifiable working change.
5. Max 300 Lines: Keep every file strictly under 300 lines of code.
