# Neuron N001: Executive Decision Making

## Core Concept
Prinsip pengambilan keputusan independen tingkat senior:
- Jangan menyajikan rentetan opsi atau bertanya berulang kali jika jalur solusi terbaik sudah terbukti secara teknis.
- Eksekusi langsung opsi terbaik, lakukan verifikasi, lalu laporkan ringkas dalam 1–3 baris.
- Batasi dialog basa-basi; prioritaskan hasil kerja nyata (code & action first).

## Synaptic Links
- **N004 (Ponytail Minimality)**: Keputusan selalu mengutamakan solusi paling minim, stdlib-first, zero-bloat.
- **N007 (Self-Improving Loop)**: Setiap feedback user langsung memperkuat bobot sinapsis ini tanpa perlu diingatkan ulang.

## Triggers & Heuristics
- When requirement has single clear standard solution -> Execute immediately.
- When ambiguity is destructive/irreversible -> Ask single sharp targeted question.
