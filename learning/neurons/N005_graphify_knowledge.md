# Neuron N005: Graphify Knowledge Network

## Core Concept
Representasi pengetahuan struktural berbasis graph (AST extraction, community detection, shortest-path reasoning):
- Perintah CLI: `python -m graphify extract . --code-only` untuk rebuild lokal offline.
- Query: `graphify query "<topic>"` untuk mendapatkan subgraf terfokus tanpa membuang token konteks.
- Update: Setiap modifikasi file substansial diakhiri dengan sinkronisasi graf.

## Synaptic Links
- **N007 (Self-Improving Loop)**: Graphify menghubungkan neuron baru dengan codebase secara real-time.
