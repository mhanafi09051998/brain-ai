# Neuron N004: Ponytail Minimality Ladder

## Core Concept
Tangga minimalisme rekayasa perangkat lunak:
1. **YAGNI**: Apakah fitur/abstraksi ini benar-benar dibutuhkan sekarang?
2. **Reuse**: Manfaatkan helper/pola yang sudah ada di codebase.
3. **Stdlib**: Gunakan pustaka standar sebelum mencari library eksternal.
4. **Native Platform**: Manfaatkan fitur native OS/browser/runtime.
5. **Shortest Diff**: Diff tersingkat yang tepat pada akar masalah selalu menang.
